A program that writes one image summing up Thursday 19 November 2026: the historic Trump-Xi-Putin summit in Shenzhen, the worldwide launch of Grand Theft Auto VI, Anthropic's debut on Nasdaq, Israel's ground operation in Gaza, the Berlin rally for Kyiv, and Voyager 1 passing one light-day from Earth — drawn as a one-page newspaper front page. The image is stored in `main.ts` (drawn by `tools/generate-entry.py` from wire reports of the day) and the program writes it out byte for byte.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
